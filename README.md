# 🍿 BucketList

BucketList is a lightweight, cinema-themed personal watchlist web application. It allows users to browse trending movies, search the TMDB database, and keep track of their viewing habits without needing an account.

## Features
* **Three-State Tracking:** Organize your media into *To Watch*, *Currently Watching*, and *Watched*.
* **Smart Syncing:** Moving a show to "Watched" automatically removes it from the other lists.
* **Privacy First:** No login required. All profile data and lists are saved directly to your browser's `localStorage`.
* **TMDB Integration:** Real-time data for new releases, trending movies, and genre filtering.
* **Custom UI:** A vintage popcorn bucket-inspired design with CSS variables and responsive grids.

## Tech Stack
* HTML5
* CSS3 (Vanilla, CSS Variables, Flexbox/Grid)
* JavaScript (ES6+, Fetch API, LocalStorage)
* [TMDB API](https://developer.themoviedb.org/docs)
